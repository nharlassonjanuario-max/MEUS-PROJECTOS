Sobre Mim

Sou Lasson Januário Nhar, estudante do curso de Informática na Universidade Save, com grande interesse pela área de tecnologia e desenvolvimento de software.

Tenho especial interesse por programação Web, desenvolvimento de sistemas e criação de soluções que possam facilitar processos e resolver problemas do dia a dia através da tecnologia.

Ao longo da minha formação, tenho desenvolvido diferentes projetos práticos, explorando tecnologias como HTML, CSS, JavaScript e Python, além de conceitos relacionados com sistemas operativos, redes, segurança e gestão de ficheiros.

Meu objetivo é continuar aprimorando os meus conhecimentos, transformar ideias em projetos funcionais e evoluir constantemente como profissional da área de Informática.

Meus Projectos

Alguns dos projetos que desenvolvi durante a minha aprendizagem e prática em tecnologia.

Mini Gestor de Ficheiros

Simulador desenvolvido para demonstrar, de forma prática, o funcionamento da gestão de ficheiros e pastas nos sistemas Windows e Linux, incluindo criação, organização e permissões de acesso.

Python Windows Linux

RaquerWiFi

Ferramenta desenvolvida para fins de aprendizagem e auditoria de segurança em redes Wi-Fi autorizadas, permitindo avaliar a resistência das palavras-passe e identificar possíveis vulnerabilidades.

Python Wi-Fi Segurança

Chongoene Computer Training Center

Sistema desenvolvido para apoiar a gestão e divulgação dos cursos do Chongoene Computer Training Center, facilitando o acesso às informações e aos serviços do centro.

HTML CSS JavaScript Firebase

Ghost Tool

Ferramenta desenvolvida para fins experimentais, com funcionalidades relacionadas com processos de diagnóstico e interação com dispositivos móveis.

Python QR Code USB

SIGUNISAVE 2.0

Protótipo de sistema desenvolvido para automatizar a geração de declarações de notas, facilitando a emissão de documentos académicos de forma rápida, organizada e digital.

⚛ React JavaScript PDF

Simulador de Teoria dos Grafos

Simulador educativo desenvolvido para demonstrar conceitos fundamentais da Teoria dos Grafos através de um mapa didático de Chongoene. Permite explorar visualmente conceitos como conectividade, caminho Euleriano e caminho Hamiltoniano.

HTML CSS JavaScript Grafos
